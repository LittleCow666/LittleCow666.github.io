# LittleCow666 GitHub Pages

This is a static, dependency-free personal site. Copy the contents of this directory to the root of `LittleCow666.github.io`.

- `index.html` is the overview page.
- `projects.html` contains project details.
- `about.html` contains profile and working style.
- `assets/site.css` and `assets/site.js` are shared by all pages.

The pages work directly on GitHub Pages without a build step. Update the copy and project links as your portfolio grows.
